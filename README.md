# 솔리테어 자동 진행 앱

영상에서 확인한 트라이픽스 카드 게임을 자동으로 진행하는 Android 앱입니다.

- 현재 공개된 카드 값으로 덱을 넘기기 전 최대한 많은 카드를 이어서 제거하는 순서를 계산합니다.
- 덱을 넘긴 뒤 새 카드가 드러나면 화면을 다시 읽어 다음 수를 계산합니다.
- 레벨 완료 후 나오는 레벨/플레이 버튼을 눌러 다음 레벨로 넘어가고, 별도의 시작 화면이 나오면 시작 버튼을 누릅니다.
- 상점이나 현금 구매 화면은 X로 닫습니다. 가격 결제 버튼은 누르지 않습니다.

## 설치와 사용

1. 저장소 **Releases**에서 `SolitaireBot.apk`를 태블릿에 내려받아 설치합니다. Android 11 이상이 필요합니다.
2. 앱을 열고 **접근성 설정 열기**를 눌러 `솔리테어 자동화` 서비스를 켭니다. Android가 제한된 설정 허용을 요구하면 앱 정보 화면에서 허용합니다.
3. 게임을 가로 화면으로 열면 위쪽 가운데에 `▶ 시작` 버튼이 나타납니다. 이 버튼으로 시작/정지합니다.

## 전략

매번 보이는 카드 중 아무 카드나 누르지 않습니다. 현재 보이는 카드의 등급별 개수를 상태로 만들어 가능한 모든 위/아래 등급 선택을 메모이제이션으로 탐색하고, 덱을 넘기기 전에 제거할 수 있는 카드 수가 가장 많은 첫 수를 고릅니다. 뒤집힌 카드 값은 알 수 없으므로 공개되는 순간 다시 계산합니다.

## 빌드

`main`에 반영되면 GitHub Actions가 디버그 APK를 빌드하고 Actions artifact와 `latest` Release에 올립니다. 수동 빌드는 Actions 탭에서 `Build APK`를 실행하면 됩니다.
